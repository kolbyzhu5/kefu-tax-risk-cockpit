# 可孚医疗集团税务风险驾驶舱 · BI 大屏设计说明

> 文档版本：v1.0 ｜ 编制日期：2026-08-17 ｜ 对应交付物：`税务风险驾驶舱-BI大屏.html`
> 数据口径：**模拟数据**（非企业真实数据）｜ 原型形态：单文件高保真交互 HTML

---

## 一、设计定位

本大屏是「业—财—税—资—档」一体化数智经营驾驶舱中**税务域的风险专题看板**，采用**工业级数据指挥舱（Command Center）**美学方向，目标是把税务风险从「事后发现、人工排查」升级为一条可追踪、可下钻、可闭环的数字化工作流：

```
风险识别 → 风险分级 → 处置跟踪 → 穿透取证 → 销号复核
```

**设计关键词**：深藏青底、霓虹青蓝发光、网格纹理、扫描光带、四角工业装饰框、tabular-nums 数字等宽、错峰入场动效。

## 二、信息架构（7 大视图）

| # | 视图 | 数据驱动（Tab 标识） | 承载内容 |
|---|---|---|---|
| 01 | 集团总览 | `overview` | 总风险得分 + 高/中/低分布 + 子公司排名 + 税负对标 |
| 02 | 风险分类 | `category` | 发票/收入成本/优惠/关联交易/个税社保 5 类卡片 + 疑点列表 |
| 03 | 处置进度 | `progress` | 待核实 / 整改中 / 已销号 三状态泳道 |
| 04 | 指标监控 | `metric` | 税负/毛利率/费用率/收入勾稽差异 12 月趋势（含预警虚线） |
| 05 | 疑点下钻 | `issues` | 18 疑点多维筛选 + 四类证据穿透弹窗 |
| 06 | 评分模型 | `model` | 四层计算架构 + 五类权重 + 动态修正因子 + 子公司演算表 |
| 07 | 实施路线图 | `roadmap` | 5 阶段时间轴 + 成功 KPI + 组织分工 + 风险应对 |

> 前 5 个视图对应原始 5 大需求；06/07 是评分模型、下钻血缘、路线图三部分深化设计后**回填到原型的交互视图**，保证「方案文档 ↔ 原型」一一对应。

### 3.4 动效参数

| 动效 | 参数 | 应用 |
|---|---|---|
| 入场 `fadeUp` | `0.6s ease both`，`translateY(14px)` | 卡片 / KPI / 疑点 / 泳道，错峰 0.02~0.34s |
| 扫描光带 `scan` | `9s linear infinite`，`translateY(0→110vh)` | 顶部扫描层 |
| LIVE 呼吸点 `blink` | `1.4s ease infinite` | 头部 LIVE 圆点 |
| 仪表盘环 | `stroke-dashoffset` 过渡 `1.4s cubic-bezier(.22,1,.36,1)` | 环形仪表盘入场 |
| 分布条宽度 | `0.8s cubic-bezier(.22,1,.36,1)` | 风险分布条 |
| 排名条宽度 | `0.9s cubic-bezier(.22,1,.36,1)` | 子公司排名填充 |
| 数字滚动 | `countUp`（JS） | KPI / 评分数字 |

> 统一缓动 `cubic-bezier(.22,1,.36,1)`（先快后慢的「easeOutQuint」近似），营造利落的驾驶舱节奏。

## 四、核心组件设计规范

### 4.1 顶栏（header）

- **品牌徽**：46×46px 切角方块，`clip-path: polygon(0 0,100% 0,100% 72%,72% 100%,0 100%)`，青蓝渐变底 + 深色「税」字，`box-shadow: 0 0 22px cyan-glow`
- **标题**：`可孚医疗集团税务风险<em>驾驶舱</em>`，`em` 高亮青色 + 发光
- **副标题**：`业 · 财 · 税 · 资 · 档 一体化数智经营 — 税务域风险专题 · TAX RISK COMMAND CENTER`
- **右侧信息区**：LIVE 呼吸点 + 实时时钟（Rajdhani 青色）+ 「数据截至 2026-07-31」徽章 + 「模拟数据」琥珀徽章

### 4.2 导航 Tab

- 7 个等分按钮，`flex:1`，未激活为透明底灰字，hover 变亮
- **激活态**：青蓝渐变底 + 深色字 + 发光，`box-shadow: 0 0 18px cyan-glow`
- 序号用 Rajdhani 小字（`opacity:.6`）

### 4.3 KPI 数字带

- 5 卡网格（`repeat(5,1fr)`），每卡左侧 2px 彩色发光竖条（`--kc` 决定色）
- 数字 34px Rajdhani 700，`text-shadow` 发光，颜色由 `--kc` / `--kg` 变量驱动

### 4.4 环形仪表盘

- 168×168px SVG，`transform: rotate(-90deg)` 让起点在顶部
- 轨道 `stroke: rgba(56,189,248,.1)`，进度环 `stroke-linecap: round` + `drop-shadow`
- 中心大字 44px 得分 + `RISK SCORE` 标签，右侧配等级 pill 与环比 delta

### 4.5 风险分布条

- 横向堆叠条带（`height:26px`），segment 内嵌数字，宽度动画
- 高/中/低三色段，hover `brightness(1.15)`，点击可联动跳转下钻

### 4.6 子公司排名

- 6 行：序号 + 名称（80px）+ 渐变填充轨道 + 得分（44px 右对齐）+ 等级 tag
- 填充条 `box-shadow: 0 0 10px currentColor`，宽度 0.9s 动画，整行 hover 可点

### 4.7 指标趋势图

- 2×2 网格卡片，每张 SVG 158px 高
- 网格线 `rgba(56,189,248,.08)`，面积图 `linearGradient` 填充 + 发光 stroke
- 5% 红色虚线预警线 + 当前值大字（22px 发光）

### 4.8 分类卡片

- 5 列网格，每卡顶部 3px 彩色发光条（`--cc` 决定色）
- 卡内：分类名 + 32px 发光得分 + 疑点数/金额 meta
- hover 上浮 3px + 发光描边；点击筛选该类疑点

### 4.9 表格

- 表头青字 `rgba(34,211,238,.06)` 底 + `line-strong` 下边框
- 行 hover `rgba(34,211,238,.04)`；数字列 Rajdhani `tabular-nums`

### 4.10 下钻弹窗

- 遮罩 `rgba(3,6,12,.72)` + `backdrop-filter: blur(4px)`，`z-index:100`
- 弹窗 800px、`max-height:90vh`、可滚动，头部 sticky
- **四类证据 Tab**：原始凭证（账流）/ 发票（票流）/ 合同（合同流）/ 资金流水（资金流）
- **证据组合映射**：`em-row` 展示该风险类型的必看证据 + 辅助证据
- **主数据关联键**：6 个 `code` 标签（sub_id / vendor_id / contract_no / invoice_no / voucher_no / bank_seq）
- **三流一致核验结论**：2×2 网格，4 条规则（合同vs发票>5%、发票vs资金>10%、凭证vs发票、申报vs财报>5%），每条带通过/异常圆点

### 4.11 评分模型视图

- **四层架构**：4 列流程卡（L1 疑点贡献分 → L2 分类得分 → L3 子公司得分 → L4 集团总分），每卡含公式块（青底等宽字）
- **五类权重**：分布条展示权重占比
- **动态修正因子**：SLA 逾期加成 / 时间衰减 / 重复疑点聚合，`fx-badge` 标签
- **演算表**：子公司得分明细 + 集团加权汇总行

### 4.12 实施路线图视图

- 左侧渐变时间轴（cyan→purple），节点发光圆点
- 每阶段：阶段号 + 名称 + 周数（琥珀 pill）+ 描述 + 产出

## 五、交互设计规范

| 交互 | 行为 |
|---|---|
| Tab 切换 | 切换视图并**重触发入场动画**（先 `animation:none` 强制回流再恢复） |
| 跨视图联动 | 总览点排名/分布色块 → 跳转「疑点下钻」并预过滤 |
| 疑点筛选 | 按子公司 / 风险等级 / 分类 / 状态多维筛选 |
| 下钻弹窗 | 点疑点 → 弹窗展示四类证据 + 核验结论 + 关联键；证据 Tab 可切换 |
| 弹窗关闭 | 关闭按钮 / 点击遮罩 |

## 七、工程实现要点

| 项 | 说明 |
|---|---|
| 交付形态 | 单文件 HTML，无外部依赖（除 Google Fonts CDN），双击即开 |
| 结构 | 纯 CSS 变量 + 原生 JS，无框架；视图由 `render*` 函数 + 模板字符串生成 |
| 数据层 | JS 对象字面量（`CATS`/`SUBS`/`ISSUES`/指标序列），与视图解耦 |
| 动画 | CSS `@keyframes` + JS `countUp` + SVG `stroke-dashoffset` |
| 响应式 | `@media(max-width:1000px)`：KPI 2 列、其余网格降为单列 |
| 质量保障 | node 校验 JS 语法；playwright 无头验证 7 Tab 切换 + 下钻弹窗 0 运行时错误 |

## 九、设计约束与注意事项

1. **字体依赖**：Rajdhani 依赖 Google Fonts CDN，离线环境会回退到 DIN Alternate / Segoe UI，不影响布局。
2. **风险配色语义**：高红 / 中橙 / 低绿为「危险信号」通用约定，切勿与股票涨跌红绿口径混淆。
3. **模拟数据**：所有数值为演示口径，正式投产需替换为真实主数据并校准评分权重。
4. **大屏适配**：当前为 1500px 居中流式布局，若需全屏 16:9 投屏，需单独适配视口缩放与字号基准。
